# Automatic Book Page Turner

MuJoCo 기반 **자동 책장 넘김 로봇** 1인 프로젝트.

## 프로젝트 목표

누운 상태에서 종이책을 손으로 지탱하거나 직접 책장을 넘기지 않도록, 책 지지 장치와 롤러·넘김 막대를 결합한 로봇을 시뮬레이션한다.

- 프로젝트 단계: **02 Requirements (3일차 요구사항 및 판정 함수 작성)**
- 현재 검증 상태: **물리적 페이지 넘김 미검증**
- 기술 후보: MuJoCo `flexcomp` / 필요 시 분절 강체 페이지

## 3일차 목표

- 버튼 입력 10회로 실제 종이책 페이지 10장을 한 장씩 순차적으로 넘기는 것을 목표로 한다.
- 합격 목표(잠정): 입력 1회당 정확히 1장만 성공(0장·2장 이상은 개별 실패), 10회 중 9회 이상 성공, 동시 2장 넘김 0회, 시도당 15초 이내. 수백 장의 책 전체를 구현하기 어려우므로 10장으로 연속 동작을 검증한다.
- 안전 요구: 책 본체 이탈 0회, 구동 범위 이탈 0회. MuJoCo의 종이·받침판 관통은 요구사항 명세에 포함하지 않고 개발 중 디버깅으로 별도 관리한다.
- 현재는 **10장 물리 동작을 구현·검증한 상태가 아니라 판정 기준만 수립한 상태**이다.

## 폴더 구조

- `scenes/`: MuJoCo MJCF XML 장면 (4일차 작성 예정)
- `src/`: 파이썬 로봇 제어 코드 (개발 단계)
- `tests/`: 테스트 및 판정 함수
- `docs/`: 과제 산출물
- `logs/`: 진행·실행 기록

## 개발 환경 (예정)

Python 3.11 이상, MuJoCo. `uv sync`로 의존성 설치 준비. 아직 실제 장면의 정상 작동은 검증되지 않았다.
