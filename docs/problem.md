# D01 v2 문제 정의서 — 누워서 읽는 사람을 위한 자동 책장 넘김

> D01 · 문제 정의서 · 작성: 프로젝트 수행자(이상혁) · 검토: 본인 자체 검토 / 지도교사 검토 예정 · 상태: 작성 · v2 · 스테이지: 01 Discovery

## 문제 한 줄

누워서 종이책을 읽을 때 손으로 책을 지지하고 페이지를 넘겨야 하므로 팔의 부담과 독서 흐름의 중단이 발생한다.

## 사용자(페르소나)

- **대표 사용자(가상):** 잠들기 전 침대에 누워 종이책을 읽는 독서자.
- **상황:** 누운 자세에서 약 20분 동안 책을 읽고 싶지만, 펼친 책을 손으로 유지하고 페이지를 넘겨야 한다.
- **목표:** 책을 직접 잡지 않고, 원하는 순간 버튼 한 번으로 다음 페이지를 읽는다.
- **근거 표기:** 위 20분은 사용자 사례를 구체화하기 위한 **가정**이며 실제 인터뷰나 관찰 결과가 아니다.

## 현재 작업 흐름(As-Is)

1. 읽을 종이책을 고른다 — **사람**
2. 눕고 읽기 편한 자세를 잡는다 — **사람**
3. 책을 손으로 들어 읽을 위치에 유지한다 — **현재 사람 / 제안 시스템의 책 지지 프레임**
4. 현재 페이지의 내용을 읽는다 — **사람**
5. 오른쪽 페이지 가장자리를 손으로 분리해 들어 올린다 — **현재 사람 / 로봇**
6. 페이지를 왼쪽으로 넘기고 펼친 상태를 정리한다 — **현재 사람 / 로봇**
7. 다음 페이지를 읽는다 — **사람** (4~7 반복)
8. 독서를 마치고 책을 치운다 — **사람**

**로봇이 맡을 단계:** 5~6단계의 페이지 분리·넘김·정리. 3단계의 지속적인 책 지지는 **지지 프레임**으로 해결한다. 책 선정·독서·종료는 사람의 몫이다.

### 제안 작업 흐름(To-Be, 목표)

사람이 책을 프레임에 고정 → 사람이 독서 → 버튼 누름 → 오른쪽 롤러로 페이지 끝 분리 시도 → 넘김 막대로 왼쪽 이동 → 왼쪽 롤러가 받쳐 정리 → 사람의 독서 재개

## 불편 지표: 현재 값과 근거

| 지표 | 현재 값 | 근거 및 상태 |
|---|---|---|
| 누워서 독서하는 한 번의 시간 | 20분 | **가정**: 페르소나 설정값. 실측 아님 |
| 독서 중 책을 손으로 지지하는 시간 | 최대 20분 | **가정**: 책을 계속 들고 읽는 경우의 상한 예시. 실제 측정 필요 |
| 페이지를 넘기기 위해 손을 움직이는 횟수 | 10회/20분 | **가정**: 2분마다 한 번이라는 예시 계산. 관찰·측정 필요 |
| 페이지 넘김 과정에서 독서가 중단되는 시간 | 미측정 | 사용자 관찰로 측정할 항목 |
| 팔의 불편 정도 | 미측정 | 독서 전·후 0~10점 자기평가 예정 |

※ 위 숫자는 프로젝트 현황을 설명하기 위한 **예시 가정**이다. 교안의 원칙에 따라 관찰·인터뷰·실측치처럼 제시하지 않는다.

## 로봇이어야 하는 이유 — 4문항 검사

| 질문 | 판단 및 이유 |
|---|---|
| 물체를 옮기거나, 움직이거나, 닿는가? | **예.** 롤러와 막대가 실제 페이지에 접촉해 분리·이동시키려 한다. |
| 같은 동작을 반복하는가? | **예.** 페이지가 바뀔 때마다 같은 동작이 필요하다. |
| 사람에게 불편·위험한가? | **불편.** 누운 상태에서 책을 지지하고 페이지를 넘기려면 손과 팔을 사용해야 한다. 불편 정도는 미측정이다. |
| 앱·센서·고정 장치로 해결되지 않는가? | **부분 해결.** 고정 장치는 책의 무게를 지지할 수 있지만, 실제 종이책의 페이지를 자동으로 넘기려면 물리적인 구동 장치가 추가로 필요하다. |

**주제 선정 판단:** 단순한 책 거치대가 아니라 *종이 페이지를 실제 접촉으로 넘기는 물리 작업*을 로봇의 범위로 삼는다.

## 시뮬레이션에서 잴 것

- 버튼 입력 이후 롤러와 막대의 동작 여부 및 순서
- 책장 끝이 들어 올려졌는지 여부
- 책장 한 장이 반대쪽으로 넘어갔는지 여부(시도 횟수·성공 횟수)
- 책장 넘기기 1회에 걸린 시뮬레이션 시간(초)
- 페이지 이탈·지지대 충돌·실패 횟수

현재는 모델 검증 전이므로 목표 성공률·허용 시간의 숫자를 확정하지 않는다. 3일차 D03에서 시험 조건과 합격 기준을 정한다.

## 범위 및 어려움

- **1차 검증:** 공중에 고정된 책 모형과 변형 가능한 페이지 **1장**의 접촉 기반 넘김.
- **후속 확장:** 여러 장 가운데 한 장씩 분리하는 기능.
- **위험:** `flexcomp` 모델의 변형 안정성, 얇은 종이 마찰, 원치 않는 복수 페이지 접촉. 물리적으로 어렵다면 분절된 강체 페이지 모델로 설계를 변경하고 사유를 기록한다.

## 검토 필요 항목

- 사용자 독서 시간·페이지 넘김 빈도·팔 불편 정도를 실제 관찰이나 인터뷰로 확인할 것.
- 1인 프로젝트 허용 여부와 정량 목표치에 대한 지도교사 검토를 받을 것.
